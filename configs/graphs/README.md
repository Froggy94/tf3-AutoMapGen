# Own graphs

Put your own graph documents here (`<id>.graph.json`). They are found before the built-in graphs, by the GUI and by
the command line. A graph here usually `extends` a built-in one and replaces or removes a few nodes; to offer it in the
GUI, add it to `graphs` in `configs/gui.toml`. How: [docsAI/reference/README.md](../../docsAI/reference/README.md).
